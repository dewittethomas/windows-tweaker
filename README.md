# Windows Tweaker
A Powershell script which applies several tweaks to your Windows 11 Installation, to improve usability.

## Tweaks
The following tweaks are applied using this script:

- Enable Dark Mode
- Align Taskbar to the Left
- Disable Taskbar Transparency Effects
- Disable Device and Display Sleep

## Usage
To run this script, you should run PowerShell as Administrator (on Windows 11) and run the following command:

```ps1
irm "https://raw.githubusercontent.com/dewittethomas/windows-tweaker/main/Script.ps1" | iex
```
